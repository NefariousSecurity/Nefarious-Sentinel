Nefarious Sentinel Core is the persistent background protection engine for
the Nefarious Sentinel Android security application. It is managed using the
separately installed Sentinel Controller, with signature-verified communication.

It supports locally configured USB data-host safeguards, check-in based
Dead Man's Switch rules and other opt-in protections subject to the Android
administration authority granted.

Installing this APK does not grant Device Owner authority. Hardened Mode
requires an explicitly authorised Android provisioning workflow, usually
before a device is fully set up. Standard Mode has fewer capabilities.

Do not install a Core signed differently from the Controller, Motion and
SMS helper applications. Optional wipe triggers can irreversibly erase a
device. Refer to the release notes and independent backups.

Based in part on Oblivion V2 by Lethe Labs. Release 1.0.0 is a prerelease.
