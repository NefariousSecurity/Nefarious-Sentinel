# Nefarious Sentinel Releases

Official release builds for Nefarious Sentinel.

Nefarious Sentinel is Android security software containing optional destructive protection features including device wipe functionality.

## Important

Beta builds should be treated as test software.

Use only on devices with appropriate backups and after reading the release notes.

Development source and internal project history are maintained separately.

## Verification

Each release includes SHA-256 hashes for integrity verification.
